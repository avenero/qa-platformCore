As a bilingual platform administrator
I want to manage content in both Spanish and English simultaneously
Para soportar una base de usuarios multilingüe

Acceptance Criteria / Criterios de Aceptación:

Given the user's browser language is set to "es-AR"
When the user first accesses the platform
Then the interface loads in Spanish (Argentina locale)
And dates use DD/MM/YYYY format
Y los montos usan formato $1.234,56

Dado que el administrador publica contenido
When he sets the language to "both"
Then the content is saved in two separate fields: content_es and content_en
Y ambas versiones son requeridas antes de publicar

Given a user switches language mid-session from English to Spanish
Cuando la página recarga
Then all UI labels switch to Spanish
And the URL changes from /en/dashboard to /es/tablero (localized routes)
Y el estado de la sesión se preserva

As a content editor
Quiero poder previsualizar el contenido en ambos idiomas antes de publicar
To catch translation errors before they reach end users

Given I have draft content in both languages
When I click "Preview All Languages"
Then I see a side-by-side comparison
Y un indicador muestra si alguna versión tiene más del 10% de diferencia en longitud (posible error de traducción)

Scenario: Fallback to English when Spanish translation is missing
Dado que existe contenido solo en inglés (sin versión en español)
When a Spanish-speaking user accesses that content
Then the English version is shown with a banner "Contenido no disponible en español"
And an alert is sent to the translation team
